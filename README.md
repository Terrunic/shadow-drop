A client-side mod that adds subtle drop shadows to items in GUIs, at a small cost to performance.

<img width="100%" alt="Shadow Drop example" src="https://github.com/user-attachments/assets/2ab817a1-1c61-429a-8771-af39e3ccc3e4" />

Shadows are highly configurable through the generated config file, or through a clearer config menu if [YACL](https://modrinth.com/mod/yacl) is installed.
